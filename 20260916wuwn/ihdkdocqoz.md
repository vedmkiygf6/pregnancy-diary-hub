# 腿疼！从8旬老人右腿里竟取出……出现这些症状要当心！

> 更新时间：2026-09-16 (UTC+8)

“唉哟，腿疼！”

在喜迎新春的热闹氛围中

85岁的于奶奶（化名）

却差点迈不过人生最难的一道坎

急性动脉栓塞

这个病是不少老年人的噩梦

出现这些症状一定要当心！

八旬老人突感腿疼麻木

本就有长期冠心病、房颤的于奶奶，近日突感右侧小腿疼痛。渐渐地，右腿的皮肤看起来白惨惨的，摸起来凉凉的，而且越来越麻木。

 

腿一天比一天疼，令她寝食难安，到后来连走路都不能了。家人急忙把于奶奶送到深圳市人民医院介入科就诊。

 

经查体及双下肢增强CTA检查发现，患者右侧的腘动脉、胫后动脉和足背动脉搏动消失；右侧下肢血管多发明显狭窄、闭塞；下肢动脉硬化。 

凶险的血管外科急症！

 

介入科医生眉头一皱，患肢苍白（pallor）、无脉（pulselessness）、感觉异常（paresthesia）、运动障碍（paralysis）、持续性疼痛（pain），这正是典型的下肢急性缺血的主要临床表现“5P”征。

 

呀，于奶奶遇上了一种非常凶险的血管外科急症——因房颤产生相关栓子脱落造成的**急性下肢动脉闭塞**，而且缺血情况严重！这种病对高龄患者来说尤其棘手。

医生告诉家属，需尽早手术恢复血管腔通畅、保证患肢血液供应。手术推迟越久，预期效果越差，最终有可能导致肢体不可逆的坏死从而进行截肢，且长期患肢缺血缺氧产生的有毒物质进入血液循环可导致肾功能衰竭进而危及生命！

 

**急性下肢动脉闭塞**

常因近端来源的栓子脱落下来堵塞了肢体动脉或原有动脉发生急性血栓形成，引起肢体血液灌注的骤然下降，造成肢体急性缺血、缺氧、代谢障碍。长期血管闭塞可造成患肢缺血性坏死甚至危及生命。

心房颤动、大血管的动脉瘤、主动脉粥样硬化等都是导致急性动脉闭塞的危险因素。虽目前诊疗技术飞跃进步，但外周急性动脉栓塞的患肢丢失率仍居高不下，且老年人群占较高比例。

保住老人的腿！微创手术来帮忙

 

时间就是生命！为了尽最大努力保住老人的腿，深圳市人民医院介入科陈旭东教授团队紧急和全院多学科反复讨论，认为**经皮经腔血管成形术**（介入PTA）是目前最适合的治疗方式。这种血管腔内微创手术创伤小、恢复快，可去除血栓、恢复血管正常腔内血流，提高患者预后生活质量。

 

最终，在陈旭东教授团队的努力下，历经3.5个多小时完成了这项高难度手术操作。何凡副主任医师采用微导丝、微导管耐心寻找血管真腔，成功通过血管闭塞段，清除了栓子；后予以球囊扩张以及导管抽栓等处理，成功恢复患肢下肢血管血流，保障患肢远端血液供应，保住了患者右腿。

 

手术中

术后老人恢复良好，疼痛明显减轻并逐渐消失，予以留置动脉导管间断溶栓处理，12小时后肢体温度、颜色和感觉明显改善，足背动脉搏动有力，说明右侧肢体血液灌注明显改善。

 

术中取出血栓

**警惕“5P”征，及时就诊**

急性外周动脉闭塞具有急性发病、进展迅速、高致残率和死亡率的特点，由于腔内血管治疗的极高的专业技术要求以及相关知识普及欠缺，相当一部分患者不认识介入治疗的优势特点而没有得到良好的治疗，病情迁延截肢率高。

 

深圳市人民医院介入科医生提醒广大市民，针对此类急、慢性血管闭塞类疾病，及时、尽早恢复患肢血流最为关键，保障患肢存活率；患者要警惕急性动脉栓塞“5P”的临床表现，及时就诊。

**深圳市人民医院介入科**

每年进行介入手术4000余台，对于血管类疾病具有相关配套诊疗硬件措施，除了导丝、球囊等溶碎栓器材，还有近年新的血管内减容设备如准分子冷激光血管内消融、Turbohawk硬化斑块旋切装置、Angiojet血栓抽吸系统等，为日常介入诊疗提供了有力保障。很多下肢血管病患避免了截肢或大大降低了截肢平面，不少外地患者也慕名而来。
