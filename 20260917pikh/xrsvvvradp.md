01

//  

到院时，所有人员需自觉佩戴好口罩，主动出示闽政通**健康码、行程码，**并扫描预检分诊入口处**张贴码**进行登记。

05

//

06

//  

在厦患者非必要不离厦，不去中高风险地区，减少人员流动。因疫情影响，**外地患者可选择线上远程看诊服务**，或待情况稳定后再来院看诊。

07

//  

我院**无发热门诊**，请到指定医院发热门诊就诊。

我院不接待持**红、黄码**患者。

//  

厦门现已为低风险地区，根据【厦门疾控最新提醒!】异地低风险地区患者入厦需第一时间就近进行核酸检测，然后持**48小时核酸报告及绿码、行程码**，方可有序到院就诊。
