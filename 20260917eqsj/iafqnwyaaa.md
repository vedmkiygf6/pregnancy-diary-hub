# 黄体酮肌肉注射时的皮肤护理

> 更新时间：2026-09-17 (UTC+8)

黄体支持是辅助生殖技术的常规治疗，黄体支持的药物及给药方式虽多，但是由于经济原因等因素的限制，肌肉注射黄体酮仍然是辅助生殖技术黄体支持最常用的给药途径。黄体酮为油剂，肌肉注射后局部会产生硬结，是临床上常见的并发症。

肌肉注射产生硬结的原因主要有：

1. 药物因素 黄体酮粘稠度大、不溶于水，难以扩散。

2. 操作因素 护理人员操作不规范，动作粗暴，在同一部位反复注射，注射深度不够，药物注入脂肪未达肌层，注射时推药速度过快，组织间隙承受不了较大的压力撕裂性损伤。

3. 患者因素 长期卧床，血液循环差，患者体质差，肥胖患者。

4. 心理因素 恐惧、紧张都会造成肌肉痉挛，药物不易吸收。

预防措施：

1. 黄体酮为深部肌肉注射，患者带回注射的一定要到正规诊所注射，不可在家自行注射。

2. 护理人员掌握药理作用，掌握正确肌肉注射技巧，选择合适针头及正确的注射部位，避免反复穿刺同一部位。

3. 做好心理护理

硬结的治疗方法有哪些呢？以下介绍几种经济又实用的方法：

1. 60-70摄氏度水100ML加入50G硫酸镁，搅拌均匀，用纱布或毛巾浸湿，拧干，热敷硬结处，3-5分钟更换一次，持续20-30分钟，一天3-4次，配合按摩效果更好。

2. 新鲜土豆洗净切片，削成0.5-1.0CM厚度的比硬结处略大的片，敷在硬结处，然后2条胶布固定。24小时后取下，硬结明显缩小，次日同法再贴1，一般1-2片土豆可使硬结缩小。

3. 将新鲜的白萝卜洗净，横切成3MM厚度的薄片，贴于硬结处，盖上塑料薄膜，胶布固定。一天一次，坚持数日必有效果。

4. 新鲜鸡蛋清倒入消毒棉球，敷于硬结处，盖上纱布，胶布固定，一天一次，数日见效。

5. 冰片2克加75%酒精200ML溶解，干净纱布轻擦硬结处，一次5-10分钟，连续3-5天见效。

6. 根据硬结大小，取鲜仙人掌一片，去掉小面小刺，用小刀剥开，贴于硬结处，胶布固定，24小时换一次，1-2次即愈。
