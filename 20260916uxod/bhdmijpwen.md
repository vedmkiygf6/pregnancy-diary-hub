# 睡眠频道丨“鬼压床”是什么？

> 更新时间：2026-09-16 (UTC+8)

**开栏语**

“良好睡眠，健康心理”是每个人的愿望。每个人皆可成为自己的疗愈师。发挥自己主观能动性，食、动、悟、养皆可成为治疗的“良药”。**医学导师：**广东省中医院芳村医院睡眠障碍科主任 徐碧云

“鬼压床”是民间流传下来的说法。很多人在晚上睡觉时可能会经历一种令人恐惧的现象：醒来时无法动弹，感觉有一种“重压感”压在胸口，有时候还伴随有幻觉或窒息感。由于这种现象常常发生在半夜，且症状的表现非常真实，许多人会将其归因于“鬼怪作祟”。然而，从医学角度来看，所谓的“鬼压床”其实是一种叫做“睡眠麻痹”（Sleep Paralysis）的现象，是一种正常的生理反应，虽然它可能让人感到极度不适，但并不代表有任何神秘或超自然的因素。

**睡眠麻痹是怎么回事？**

睡眠麻痹是一种在清醒和睡眠之间过渡时发生的现象。它通常发生在快速眼动睡眠（REM）阶段，这一阶段是人类梦境最为活跃的时段。睡眠麻痹的本质是大脑处于清醒状态，而身体依然保持在睡眠的肌肉放松状态中，导致个体意识清醒，但无法移动。

**“鬼压床”会有哪些症状？**

“鬼压床”的症状通常包括以下几个方面：

1. **无法动弹**：最常见的表现是意识清醒，但无法动弹，尤其是无法活动四肢或转动身体。

2. **胸口压迫感**：很多人会感到胸口被重压，呼吸困难，这种感觉有时会让人误以为自己被“鬼压”。

3. **幻觉**：一些人还会在睡眠麻痹期间出现幻觉，听到声音、看到虚幻的人影或感觉有其他实体在房间里。这些幻觉常常增加恐惧感。

4. **窒息感或呼吸困难**：由于无法控制呼吸，部分人可能会感到气短或窒息。

5. **强烈的恐惧感**：由于无法动弹，又有幻觉或胸口压迫感，许多人会感到强烈的恐惧和焦虑。

**为什么会发生“鬼压床”？**

睡眠麻痹的发生是由大脑的睡眠和觉醒状态之间的暂时失调引起的。正常情况下，在睡眠的快速眼动阶段，大脑活跃而清晰地进行梦境加工，但为了避免做梦时做出实际的动作，身体会进入一种暂时性的肌肉麻痹状态，防止人们在梦中做出不适当的肢体动作。然而，在某些情况下，身体在进入或醒来时，肌肉麻痹并没有及时解除，而大脑已经恢复了清醒意识，导致患者无法动弹，同时仍然感知到“压迫感”或恐惧。

**哪些因素可以增加“鬼压床”的发生？**

除了这种生理因素，以下一些因素也可能增加发生“鬼压床”的风险：

1. **睡眠不足**：长期缺乏充足的睡眠，尤其是睡眠不规律，容易引发睡眠麻痹。

2. **压力和焦虑**：心理压力、焦虑或情绪波动大时，容易出现睡眠障碍，从而增加睡眠麻痹的发生频率。

3. **不良睡姿**：睡姿不当，特别是仰卧时，容易导致睡眠麻痹。

4. **睡眠障碍**：如失眠、打鼾、睡眠呼吸暂停等问题，会增加睡眠麻痹的发生率。

5. **遗传因素**：如果家庭中有人曾经历过睡眠麻痹，其他成员也可能更容易发生这种现象。

**“鬼压床”是危险的吗？**

虽然“鬼压床”让人感到非常害怕，但它本身并不具有危险性。睡眠麻痹本质上并不会对身体造成伤害，症状通常持续时间较短，一般在几秒钟到几分钟内自行缓解。虽然经历时可能非常痛苦，但并不会导致持久的健康问题。

然而，如果睡眠麻痹经常发生或伴随严重的焦虑情绪，可能会影响个人的睡眠质量，甚至引发失眠等问题，进而影响到日常生活。因此，如果出现频繁的睡眠麻痹症状，建议寻求医生帮助，进行睡眠评估和相关治疗。

**如何预防和缓解睡眠麻痹？**

## **1.保持良好的作息规律**：确保每天都有足够的睡眠时间，避免熬夜，尽量保持固定的入睡和起床时间。

## 2. **减少压力**：通过冥想、深呼吸、瑜伽等方式缓解日常的压力和焦虑，保持情绪稳定。

## 3. **改善睡眠环境**：保持安静、舒适的睡眠环境，避免噪音、光线等干扰因素。

## 4. **避免仰卧睡姿**：睡眠时可以尝试改变睡姿，避免长期仰卧，避免增加睡眠麻痹发生的几率。

## 5. **避免兴奋性饮料和食物**：睡前避免摄入咖啡因、酒精等刺激性饮料或食物，它们可能影响睡眠质量，增加发生睡眠麻痹的风险。

**小结**

“鬼压床”是一种常见的睡眠现象，其医学名称为睡眠麻痹。它通常发生在快速眼动睡眠（REM）阶段，是由于大脑清醒而身体仍处于睡眠状态导致的。虽然睡眠麻痹可能会引发强烈的恐惧感，但它本身并不具有危害性。通过保持规律的作息、减轻压力以及改善睡眠环境等措施，可以有效预防睡眠麻痹的发生。如果症状频繁或对生活质量造成影响，建议及时就医，寻求专业的帮助和治疗。
